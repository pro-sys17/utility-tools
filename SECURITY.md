# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
We take the security and privacy of UtilityHub seriously. Since all core utilities process documents locally inside the browser runtime, security vulnerabilities typically relate to client-side injection, prototype pollution, cross-site scripting (XSS), or unsafe object URL handling.

If you discover a potential vulnerability:
1. Please do NOT disclose it publicly on GitHub issues.
2. Email security findings to `security@utilityhub.dev` with detailed steps to reproduce.
3. We will respond within 48 hours to confirm receipt and provide an estimated remediation timeline.
